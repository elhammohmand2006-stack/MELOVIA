# 🎵 MELOVIA

**MELOVIA** is a modern music platform designed to help users discover, explore, and enjoy music through a simple, interactive, and user-friendly interface.

## ✨ Features

- 🎵 Modern and clean music platform design
- 🏠 Multiple interactive pages
- 🔎 Discover and explore music
- 🎤 Explore artists and albums
- 🎼 Browse music by genres
- 🎫 Explore upcoming music events
- 📩 Contact section
- 🌙 Dark Mode and ☀️ Light Mode
- ✨ Smooth animations and interactive elements
- 📱 Responsive design for different screen sizes

## 📄 Pages

The MELOVIA website includes the following sections in order:

1. **Home**
2. **Discover**
3. **Artists**
4. **Albums**
5. **Genres**
6. **Events**
7. **Contact**

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Responsive Web Design
