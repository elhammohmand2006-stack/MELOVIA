# 🎵 MELOVIA

**MELOVIA** is a modern multi-page music platform designed to help users discover, explore, and enjoy music through a simple, interactive, and user-friendly interface.

The platform brings together music discovery, artists, events, and genres in one organized experience with a clean and modern design.

## ✨ Features

- 🎧 Discover and explore music
- 🎤 Explore different artists
- 🎼 Browse music by genres
- 🎟️ Explore upcoming music events
- 🏠 Modern and responsive home page
- 📖 About section for information about MELOVIA
- 🧭 Easy navigation between pages
- 📱 Responsive design for different screen sizes
- 🌙 Dark and light mode
- ✨ Interactive elements and animations
- 🎨 Modern music-focused user interface

## 📄 Pages

MELOVIA includes the following pages:

### 🏠 Home
The main landing page of the platform, introducing MELOVIA and highlighting music content.

### 🔎 Discover
A space where users can explore and discover different music and featured content.

### 🎤 Artists
Allows users to explore artists and learn more about them.

### 🎟️ Events
Displays music-related events and provides information about upcoming events.

### 🎼 Genres
Organizes music into different genres, making it easier for users to find the type of music they enjoy.

### ℹ️ About
Provides information about the MELOVIA platform and its purpose.

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/elhammohmand2006-stack/MELOVIA.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd MELOVIA
```

### 3. Run the website

Open `index.html` in your browser.

For the best development experience, you can also use **Visual Studio Code** with the **Live Server** extension.
